# Keyboard controls

| Key | Action |
| --- | --- |
| Arrow keys / `j`, `k` | Navigate |
| `Enter` | Play selected track or activate item |
| `Space` | Play/pause |
| `a` / `Shift+a` | Append to queue / play next |
| `n` / `b` | Next / previous |
| Left / Right | Seek 5 seconds |
| Shift+Left / Shift+Right | Seek 30 seconds |
| `+` / `-` / `0` | Volume up / down / mute |
| `s` / `r` | Shuffle / repeat |
| `/` or `Ctrl+f` | Search |
| `u` | Undo queue edit |
| `f` / `p` | Add to favorites / Quick Picks playlist |
| `Ctrl+1` / `Ctrl+2` | Local / Spotify Remote |
| `Backspace` | Return from album, artist, or genre tracks |
| `,` | Settings |
| `?` | Context help |
| `Ctrl+q` | Save session and quit |
